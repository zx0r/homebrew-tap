### Installation

```shell
# Direct Install (Standalone)
brew install zx0r/tap/<formula>
```

*Example:*
```bash
brew tap zx0r/tap
brew install <formula>
```
---

## Supported Architectures

All formulas distribute pre-compiled, SHA-256 verified release binaries:

- **macOS**: Apple Silicon (`aarch64`) & Intel (`x86_64`)
- **Linux**: Standard GNU / glibc (`x86_64`)
